Tags de Tabelas

As tags de tabelas são utilizadas para criar tabelas em uma página HTML. As tabelas são úteis para apresentar informações tabulares, como dados estatísticos, preços de produtos, informações de contato, entre outros.

Para criar uma tabela em HTML, é necessário utilizar as seguintes tags:

<table> - Define a tabela

A tag <table> é utilizada para definir a tabela em HTML.

Atributos da tag <table>:

border: define a largura da borda da tabela.

Exemplo:

Exemplo do uso de <table>


            <table border="1">
            ...
            </table>

<tr> - Define uma linha da tabela

A tag <tr> é utilizada para definir uma linha da tabela.

Exemplo:

Exemplo do uso de <tr>


            <table>
                <tr>
                ...
                </tr>
            </table>

<th> - Define uma célula de cabeçalho da tabela

A tag <th> é utilizada para definir uma célula de cabeçalho da tabela. As células de cabeçalho são geralmente utilizadas na primeira linha da tabela e são exibidas em negrito.

Atributos da tag <th>:

colspan: define o número de colunas que a célula deve ocupar.

rowspan: define o número de linhas que a célula deve ocupar.

Exemplo do uso de <th>


            <table>
                <tr>
                <th>Nome</th>
                <th>Idade</th>
                <th>País</th>
            </tr>
            </table>

<td> - Define uma célula da tabela.

A tag <td> é utilizada para definir uma célula da tabela.

Atributos da tag <td>:

  • colspan: define o número de colunas que a célula deve ocupar.
  • rowspan: define o número de linhas que a célula deve ocupar.

Exemplo do uso de <td>


            <table>
                <tr>
                <td>João</td>
                <td>30</td>
                <td>Brasil</td>
                </tr>
            </table>

<caption> - Define um título para a tabela

A tag <caption> é utilizada para definir um título para a tabela.

Exemplo do uso de <caption>

 
            <table>
                <caption>Tabela de Preços
                    ...
            </table>

Essas são algumas das tags de tabelas mais comuns utilizadas em uma página HTML. É importante lembrar que a utilização correta das tags de tabelas e seus atributos é essencial para garantir a correta formatação da tabela e sua apresentação visual adequada para o usuário.

Elementos de Multimídia

Além de texto e imagens, o HTML também permite a inserção de elementos de multimídia, como vídeos, áudios e animações. Neste capítulo, vamos abordar algumas das tags de multimídia mais comuns em HTML.

  1. Inserindo vídeos - <video>

    A tag <video> é utilizada para inserir vídeos em uma página HTML.

    Atributos da tag <video>:

    • src: define a URL do vídeo.
    • width: define a largura do vídeo em pixels.
    • height: define a altura do vídeo em pixels.
    • controls: adiciona controles de reprodução (play, pause, volume, etc) ao vídeo.

    Exemplo do uso de <video>

    
                        <video src="video.mp4" width="640" height="360" controls></video>

  2. <audio> - Inserindo áudio

    A tag <audio> é utilizada para inserir áudios em uma página HTML.

    Atributos da tag <audio>:
    • src: define a URL do áudio.
    • controls: adiciona controles de reprodução (play, pause, volume, etc) ao áudio.

    Exemplo do uso de <audio>

    
                        <audio src="audio.mp3" controls></audio>

  3. <source> - Inserindo múltiplos formatos de mídia

    A tag<source> é utilizada para especificar múltiplos formatos de mídia para o mesmo conteúdo. Isso é útil para garantir que o conteúdo seja reproduzido em todos os navegadores e dispositivos.

    Atributos da tag <source>:
    • src: define a URL do conteúdo.
    • type: define o tipo MIME do conteúdo.

    Exemplo do uso de <source>

    
                    <video width="640" height="360" controls>
                        <source src="video.mp4" type="video/mp4">
                        <source src="video.webm" type="video/webm">
                        <source src="video.ogg" type="video/ogg">
                        Seu navegador não tem suporte para esse tipo de arquivo.
                    </video>

  4. <embed> - Inserindo animações

    A tag <embed> é utilizada para inserir animações em uma página HTML.

    Atributos da tag <embed>:
    • src: define a URL da animação.
    • width: define a largura da animação em pixels.
    • height: define a altura da animação em pixels.

    Exemplo do uso de <source>

    
                        <embed src="animacao.swf" width="640" height="360">
