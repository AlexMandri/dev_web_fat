Aula 1 - Introdução ao HTML

HTML é um acrônimo que significa Hyper Text Markup Language, que é usado para criar páginas da web e aplicativos da web. Vamos ver o que significa Linguagem de Marcação de Hipertexto e página da Web.

Hipertexto: Hipertexto significa simplesmente "Texto dentro do Texto". Um texto tem um link dentro dele, é um hipertexto. Sempre que você clicar em um link que o leva a uma nova página da Web, você clicou em um hipertexto. Hipertexto é uma maneira de vincular duas ou mais páginas da Web (documentos HTML) entre si.

Linguagem de marcação: Uma linguagem de marcação é uma linguagem de computador usada para aplicar convenções de layout e formatação a um documento de texto. A linguagem de marcação torna o texto mais interativo e dinâmico. Ele pode transformar texto em imagens, tabelas, links, etc.

Página da Web: Uma página da Web é um documento normalmente escrito em HTML e traduzido por um navegador da Web. Uma página da Web pode ser identificada inserindo um URL. Uma página da Web pode ser do tipo estático ou dinâmico. Com a ajuda apenas do HTML, podemos criar páginas da Web estáticas.

Portanto, HTML é uma linguagem de marcação usada para criar páginas da Web atraentes com a ajuda de estilo e que tem um formato agradável em um navegador da Web. Um documento HTML é feito de muitas tags HTML e cada tag HTML contém um conteúdo diferente.

Conceitos Básicos de HTML

HTML é a sigla para HyperText Markup Language, que em português significa Linguagem de Marcação de Hipertexto. É a linguagem utilizada para criar conteúdo na web, ou seja, é o que permite criar páginas web e apresentar conteúdo na internet.

A estrutura básica de um documento HTML consiste em uma série de tags que definem a estrutura, o layout e o conteúdo da página. As tags são utilizadas para criar diferentes elementos na página, como textos, imagens, links, tabelas, formulários e outros.

As tags são identificadas por colchetes angulares ("<" e ">" ) e são geralmente utilizadas em pares de tags de abertura e fechamento. A tag de abertura começa com o nome da tag, enquanto a tag de fechamento começa com o mesmo nome, mas com uma barra antes do nome da tag. Por exemplo:

<p>Este é um parágrafo de texto</p>

Neste exemplo, a tag <p> é utilizada para criar um parágrafo de texto e é fechada com a tag </p>.

Além das tags de abertura e fechamento, existem também tags de auto-fechamento, que não possuem uma tag de fechamento correspondente. Um exemplo de tag de auto-fechamento é a tag <img>, que é utilizada para inserir imagens na página.

Outro conceito importante do HTML é a estrutura básica de um documento HTML, que consiste em uma série de tags que definem a estrutura, o layout e o conteúdo da página. A estrutura básica inclui a tag <HTML>, que é a tag principal do documento, a tag <head>, que contém informações sobre a página, como o título e a descrição, e a tag <body>, que contém o conteúdo principal da página.

Por fim, é importante ressaltar que o HTML é uma linguagem de marcação, ou seja, ela não é uma linguagem de programação. Isso significa que ela não possui capacidade de realizar cálculos ou tomar decisões, mas sim de criar elementos e estruturar o conteúdo da página web. Para adicionar interatividade e dinamismo à página, é necessário utilizar outras linguagens, como o JavaScript.

A estrutura de um documento HTML é importante para que o navegador possa interpretar corretamente o conteúdo da página. A estrutura básica de um documento HTML é composta por uma série de tags que definem a estrutura, o layout e o conteúdo da página.

Abaixo, segue um exemplo de estrutura básica de um documento HTML: Exemplo de um Documento HTML

<!DOCTYPE html>
<html>
<head>
<title>Título da Página</title>
</head>
<body>
<h1>Título Principal</h1>
<p>Este é um parágrafo de texto.</p>
</body>
</html>

A tag <!DOCTYPE html> define o tipo de documento que está sendo utilizado. No caso do exemplo acima, estamos utilizando a versão mais recente do HTML, que é a HTML5.

A tag <html> é a tag principal do documento e contém todas as outras tags do documento. Ela é composta por duas partes: a tag de abertura <html> e a tag de fechamento </html>.

A tag <head> contém informações sobre a página, como o título da página, a descrição, palavras-chave e outros metadados. Ela é composta por duas partes: a tag de abertura <head> e a tag de fechamento </head>.

Dentro da tag <head>, é comum encontrar a tag <title>, que define o título da página. O título da página é exibido na aba do navegador e é utilizado pelos motores de busca para identificar o conteúdo da página.

A tag <body> contém todo o conteúdo da página, como texto, imagens, vídeos, tabelas e outros elementos. Ela é composta por duas partes: a tag de abertura <body> e a tag de fechamento </body>.

Dentro da tag <body>, é possível utilizar diversas outras tags para definir diferentes elementos da página, como a tag <h1> para títulos principais, a tag <p> para parágrafos de texto, a tag <img> para inserir imagens e outras.

É importante lembrar que a estrutura básica de um documento HTML pode variar de acordo com a necessidade da página. Porém, é fundamental que o documento tenha uma estrutura bem definida para que o navegador possa interpretar corretamente o conteúdo da página.

Tags de Texto

As tags de texto são utilizadas para criar conteúdo textual em uma página HTML. Abaixo, segue uma lista com algumas das tags de texto mais comuns:

<h1> a <h6> - Tags de Título

As tags <h1> a <h6> são utilizadas para criar títulos na página. A tag <h1> é utilizada para o título principal da página, enquanto as tags <h2> a <h6> são utilizadas para títulos secundários.

Exemplo:

<h1>Título Principal</h1>

<h2>Título Secundário</h2>

A tag <p> é utilizada para criar parágrafos de texto na página.

<p>Este é um parágrafo de texto.</p>

<b> e <strong> - Tags de Texto em Negrito

<b>Este texto está em negrito.</b>

<strong>Este texto é importante e está em negrito.</strong>

As tags <b> e <strong> são utilizadas para destacar um texto em negrito na página. A diferença entre elas é que a tag <b> é utilizada apenas para destacar o texto, enquanto a tag <strong> é utilizada para destacar um texto importante.

<i> e <em> - Tags de Texto em Itálico

As tags <i> e <em> são utilizadas para destacar um texto em itálico na página. A diferença entre elas é que a tag <i> é utilizada apenas para destacar o texto, enquanto a tag <em> é utilizada para destacar um texto importante.

Exemplo:

<i>Este texto está em itálico.</i>

<em>Este texto é importante e está em itálico.</em>

<u> - Tag de Texto Sublinhado

A tag <u> é utilizada para sublinhar um texto na página.

Exemplo:

<u>Este texto está sublinhado.</u>

<s> e <del> - Tags de Texto Tachado

As tags <s> e <del> são utilizadas para criar um texto tachado na página. A diferença entre elas é que a tag <s> é utilizada apenas para criar o efeito de tachado no texto, enquanto a tag <del> é utilizada para indicar que o texto foi deletado ou removido.

Exemplo:

<s>Este texto está tachado.</s>

<del>Este texto foi removido.</del>

<sub> e <sup> - Tags s de Texto Subscrito e Sobrescrito

As tags <sub> e <sup> são utilizadas para criar texto subscrito e sobrescrito na página. A tag <sub> é utilizada para criar texto subscrito, enquanto a tag <sup> é utilizada para criar texto sobrescrito.

Exemplo:

X<sub>2</sub> + Y<sup>2</sup> = Z<sup>2</sup>

X2 + Y2 = Z2

Essas são algumas das tags de texto mais comuns utilizadas em uma página HTML. É importante lembrar que a escolha da tag correta para cada tipo de conteúdo ajuda.

Tags de Imagem

As tags de imagem são utilizadas para adicionar imagens a uma página HTML. Abaixo, seguem algumas das tags de imagem mais comuns:

<img> - Tag de Imagem

A tag <img> é utilizada para adicionar uma imagem à página HTML. É importante lembrar que a tag <img> não tem tag de fechamento, e sim apenas uma tag de abertura.

Atributos da tag <img>:

  • src: indica o caminho para a imagem.
  • alt: fornece um texto alternativo para a imagem, caso ela não seja exibida corretamente.
  • width e height: definem a largura e altura da imagem, respectivamente.

Exemplo:

Exemplo do uso de img

<img src="caminho_da_imagem.jpg" alt="Imagem de um gato" width="500" height="500">

<figure> e <figcaption> - Tags de Figura e Legenda

As tags <figure> e <figcaption> são utilizadas para adicionar uma figura com uma legenda à página HTML.

A tag <figure> envolve a imagem e a tag <figcaption> é utilizada para adicionar a legenda.

Exemplo:

Exemplo do uso de figure

<figure> <img src="caminho_da_imagem.jpg" alt="Imagem de um gato" width="500" height="500"> <figcaption>Imagem de um gato.</figcaption> </figure>

<map> e <area> - Tags de Imagem com Área Clicável

As tags <map> e <area> são utilizadas para criar uma imagem com uma área clicável. É possível definir áreas clicáveis em uma imagem e adicionar links a essas áreas.

A tag <map> é utilizada para definir a imagem e as áreas clicáveis, enquanto a tag <area> é utilizada para definir as áreas clicáveis.

Exemplo:

Exemplo do uso de Map

<img src="caminho_da_imagem.jpg" alt="Imagem com áreas clicáveis" usemap="#mapa">

<map name="mapa"> <area shape="rect" coords="0,0,50,50" href="link1.html" alt="Área 1"> <area shape="rect" coords="50,50,100,100" href="link2.html" alt="Área 2"> </map>

Essas são algumas das tags de imagem mais comuns utilizadas em uma página HTML. É importante lembrar que a utilização correta das tags de imagem e seus atributos é essencial para garantir a exibição correta das imagens na página. Tags de Links

As tags de links são utilizadas para adicionar links a uma página HTML. Abaixo, seguem algumas das tags de links mais comuns:

<a> - Tag de Link

A tag <a> é utilizada para criar um link em uma página HTML.

Atributos da tag <a>:

href: define o destino do link.

target: define onde o link será aberto (ex: _blank para abrir em uma nova janela).

title: fornece uma descrição do link.

Exemplo:

Exemplo do uso de <a>

<a href="http://www.google.com" target="_blank" title="Google">Clique aqui para visitar o Google</a>

<nav> - Tag de Navegação

A tag <nav> é utilizada para criar uma lista de links de navegação em uma página HTML.

Atributos da tag <nav>:

Nenhum atributo obrigatório.

Exemplo do uso de <nav>

<nav>
<ul>
<li><a href="index.html">Início</a></li>
<li><a href="sobre.html">Sobre</a></li>
<li><a href="contato.html">Contato</a></li>
</ul>
</nav>

<link> - Tag de Ligação

A tag <link> é utilizada para ligar uma página HTML a outros arquivos externos, como arquivos CSS ou fontes.

Atributos da tag <link>:

rel: define o tipo de relação entre a página HTML e o arquivo externo (ex: stylesheet para um arquivo CSS).

href: define o caminho para o arquivo externo.

Exemplo:

Exemplo do uso de <link>

<head> <link rel="stylesheet" href="estilo.css"> </head>

Essas são algumas das tags de links mais comuns utilizadas em uma página HTML. É importante lembrar que a utilização correta das tags de links e seus atributos é essencial para garantir a correta navegação entre as páginas e a correta ligação com outros arquivos externos.

Tags de Listas

As tags de listas são utilizadas para criar listas em uma página HTML. Existem três tipos de listas em HTML: lista não ordenada (<ul>), lista ordenada (<ol>) e lista de definição (<dl>).

<ul> - Lista não ordenada

A tag <ul> é utilizada para criar uma lista não ordenada em uma página HTML.

Atributos da tag <ul>:

Nenhum atributo obrigatório.

Exemplo:

Exemplo do uso de <ul>

<ul> <li>Item 1 <li>Item 2 <li>Item 3 </ul>

<ol> - Lista ordenada

A tag <ol> é utilizada para criar uma lista ordenada em uma página HTML.

Atributos da tag <ol>:

type: define o tipo de enumeração utilizada na lista (ex: 1 para números, a para letras minúsculas, A para letras maiúsculas, i para números romanos em minúsculas, I para números romanos em maiúsculas).

start: define o valor inicial da enumeração.

Exemplo do uso de <ol>

<ol type="1" start="3"> <li>Item 3</li> <li>Item 4</li> <li>Item 5</li> </ol>

<dl> - Lista de definição

A tag <dl> é utilizada para criar uma lista de definição em uma página HTML.

Atributos da tag <dl>:

Nenhum atributo obrigatório.

Exemplo:

Exemplo do uso de <dl>

<dl> <dt>HTML</dt>
<dd>Linguagem de marcação para a criação de páginas web.</dd>
<dt>CSS</dt>
<dd>Linguagem de estilo utilizada para estilizar páginas web.</dd>
<dt>JavaScript</dt>
<dd>Linguagem de programação utilizada para criar interatividade em páginas web.</dd>
</dl>

HTML
Linguagem de marcação para a criação de páginas web.
CSS
Linguagem de estilo utilizada para estilizar páginas web.
JavaScript
Linguagem de programação utilizada para criar interatividade em páginas web.

Essas são algumas das tags de listas mais comuns utilizadas em uma página HTML. É importante lembrar que a utilização correta das tags de listas e seus atributos é essencial para garantir a correta formatação das listas e sua apresentação visual adequada para o usuário.
